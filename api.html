Connect your software to SAFE Legal

The SAFE Legal API lets your HR, payroll or intranet software read your issued policies, receive renewal and change-in-law alerts, and send requests to SAFE Legal automatically. It is optional; everything is also available in your client portal.

1. Get a key

  1. Ask for API access in your client portal (tab 🔌 API access). SAFE Legal switches it on.
  2. In the same tab, click Create a key. The key starts with safe_live_ and is shown only once.
  3. Store it in your software's secure settings. Never put it in a web page, email or chat. If it is exposed, revoke it in the portal and create a new one.

2. Address

All calls go to this address (your SAFE Legal API endpoint):

(open this guide from your client portal to see your address)

Reading data uses GET with op and key in the address. Sending data uses POST with a JSON body; send it as Content-Type: text/plain and follow redirects. Every reply is JSON with "ok": true or "ok": false and an "error" message.

3. Operations

GETop=policies — your issued policies 
curl -L "BASE?op=policies&key=YOUR_KEY"
{ "ok": true, "company": "Ethika Insurance Broking Pvt. Ltd.",
  "policies": [ { "id": "doc_…", "title": "Leave policy: earned, casual and sick leave",
      "reference": "EIBPL/HR/POL/010", "stage": "Issued", "version": "1.0",
      "effectiveDate": "2026-11-01", "expiryDate": "2027-10-31", "downloadable": true } ] }
GETop=policy — one policy, with its Word file or text 
curl -L "BASE?op=policy&id=DOC_ID&format=docx&key=YOUR_KEY"   # file.base64 = Word file
curl -L "BASE?op=policy&id=DOC_ID&format=text&key=YOUR_KEY"   # text = plain text
GETop=alerts — renewals due and change-in-law alerts 
{ "ok": true,
  "renewalsDue": [ { "id": "doc_…", "title": "POSH policy", "expiryDate": "2026-12-14", "daysLeft": 46 } ],
  "lawAlerts": [ { "id": "doc_…", "title": "Leave policy", "change": "…", "summary": "…" } ],
  "lawAlertsIncluded": true }

Change-in-law alerts are included when your company has the AI assistant switched on.

GETop=catalog — documents you can request · GETop=requests — status of your requests · GETop=whoami — check a key
POSTop=request — send a request to SAFE Legal 
fetch("BASE", { method: "POST", headers: { "Content-Type": "text/plain" },
  body: JSON.stringify({ action: "api", op: "request", key: "YOUR_KEY",
    items: [ { itemId: "hr-leave" } ],                                  // from op=catalog
    custom: [ { kind: "policy", title: "Drone safety policy", details: "…" } ],
    note: "Needed for our new warehouse", urgency: "Normal",
    requestedBy: { name: "…", email: "…" } }) })
POSTop=ask — ask a question about your issued policies (AI assistant; billed) 
body: JSON.stringify({ action: "api", op: "ask", key: "YOUR_KEY",
  question: "How many days of earned leave can be carried forward?" })
→ { "ok": true, "answer": "…", "answered": true, "sources": ["Leave policy…"],
    "disclaimer": "Generated by AI from your issued policies; not legal advice." }

4. Limits and charges

  • Each company has a daily call limit (shown in the portal). Exceeding it returns "Rate limit reached"; try again later.
  • API access may carry a monthly fee, shown in the portal. Questions are billed under the AI assistant.
  • Your key can only see your own company's data.
